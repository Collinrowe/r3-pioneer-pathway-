Pioneer Pathway — mobile

Pioneer Pathway is currently a responsive web app (React) run by homeschooling parents to plan lessons, track compliance, and connect with community. Reviewing it surfaced eight primary sections reachable from a persistent sidebar on desktop, collapsing to a bottom scroll-nav + drawer on mobile web.

This map translates that structure to native iOS: a hamburger-triggered sidebar drawer (left, mirroring the web app's own drawer) replaces the bottom tab bar, since a family may check 5+ sections in a session and a drawer scales better than a cramped tab strip. Each frame below shows a section's primary top-level view; internal tabs (Community's five, Resources' four) are shown as segmented controls rather than separate screens, per scope.
